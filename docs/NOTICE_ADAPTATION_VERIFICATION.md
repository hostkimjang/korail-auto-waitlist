# 공개 프로모션 구조 변경 대응 · v1.3.3

## 변경 내용

- 공개 공지 content 또는 명확한 오늘 그만 보기 표식이 있는 경우, 클래스와 닫기 아이콘이 바뀌어도
  정확한 닫기 control만 처리합니다. 알려진 공지 layer의 무라벨 `popClose숫자` 표식은 기존 호환 범위입니다.
- 입력 라벨은 label·aria-label·aria-labelledby·title을 함께 확인합니다. 알 수 없거나 상충하는 라벨,
  결제·동의·예약 행동, 외부 form 버튼, 편집 영역·ARIA 입력, 중첩 dialog는 자동으로 닫지 않습니다.
- 추가 설문 버튼은 허용된 공개 행동과 공지 체크박스가 함께 있을 때만 인정합니다. 내용 링크·설문 참여·
  체크박스는 누르지 않습니다. 닫기 없는 창에 Esc나 native close를 시도하지 않습니다.
- 같은 layer에 이어지는 새 공지는 content fingerprint로 구분합니다. 클릭 직전에 버튼 identity와
  구조를 다시 확인하고, 불명확한 전달 결과는 반복하지 않습니다. 상한은 5회·5초입니다.
- 예약 중 재등장한 공개 공지도 같은 기준으로 처리합니다. 다른 예약 안내창은 기존 별도 정책에 남깁니다.
- 예약 버튼과 좌석 선택의 실제 이벤트 전달을 확인하고, 불명확한 요청을 재전송하지 않습니다.
  공식 안내로 중단한 세션은 읽기 전용 확인을 위해 보존하되 보호·인증 실패는 기존 중단 정책을 따릅니다.
- HTTP 200으로 반환된 검증된 보호 신호도 예약 흐름에서 중단합니다. CAPTCHA·보호 장치를 우회하지 않습니다.
- 실패 진단에는 원문·URL·임의 클래스·개인정보 대신 제어 유형·위험 태그·공지 표식만 48시간 보존합니다.
  새 구조 관측은 고정 HTML fixture, 실패 회귀, 수정안 검토의 입력이며 자동 코드 수정·배포를 허용하지 않습니다.
- 브라우저 이미지의 Python 의존성을 전용 가상환경에 격리하고 네이티브 클릭 CI 매트릭스를 추가했습니다.

- [x] 마지막 정책 보완 뒤 공지·예약 driver/actor·보호·네이티브 클릭 관련 266건 통과.

- [x] 기존 이미지·설문·링크 공지, 클래스·아이콘 변경, 겹침·긴 공지·연속 내용, 모호한 동의·결제·입력 거부,

- [ ] 원격 CI와 플랫폼별 네이티브 결과 확인. 로컬 fixture 통과와 구분.

## 재현 환경 주의

프로젝트 권장 Node는 22입니다. Node 26 native localStorage와 jsdom 충돌로 기본 웹 테스트가 실패하는
환경에서는 `NODE_OPTIONS=--no-experimental-webstorage npm test`로 999건 통과를 확인했습니다.
기존 Dockerfile의 비고정 pip 설치는 새 의존성으로 기존 SRT schema 회귀와 타입검사가 달라질 수 있습니다.
전체 검증은 `uv.lock`에서 export한 고정 버전으로 수행했으며, 배포 이미지의 의존성 고정은 별도 개선 대상입니다.
Python 3.12가 없는 host에서는 lock 확인이 실행되지 않으므로 Python 3.12 격리 환경을 사용하세요.
이번 변경은 lock을 바꾸지 않았습니다. 개별 설치·계정·세션·예약·배포 이력은 이 공개 문서 범위에서 제외합니다.

## 적용 범위

새 환경변수·DB migration은 없습니다. 실제 운영 배포는 별도 승인 후 최신 작업 상태를 확인하고 기존
운영 가이드의 전체 프로필 재빌드·정상 drain 절차를 사용하세요. 이 공개 릴리스 준비 과정에서
운영 서비스 재시작·감시 중단·실제 철도 예약·결제를 실행하지 않았습니다.
