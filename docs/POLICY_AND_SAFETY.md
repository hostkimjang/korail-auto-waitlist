# 안전 원칙과 사용 범위

레일웨잇이 제공하는 기능, 제공하지 않는 기능, 정보를 표시하는 기준을 설명합니다.

## 비공식 프로젝트

레일웨잇은 한국철도공사(KORAIL) 또는 주식회사 에스알(SR)의 공식 서비스나 제휴 제품이 아닙니다. 운영사 이름과 상표는 열차를 구분하고 공식 채널을 안내하기 위해서만 사용합니다.

공식 앱과 홈페이지의 이용약관, 접근 제한, 예약·결제 규칙이 항상 우선합니다.

## 시간표와 좌석 정보

시간표는 열차가 운행하는 시각과 구간을 나타냅니다. 좌석 정보는 특정 시점에 확인한 상태입니다. 둘은 같은 정보가 아닙니다.

- 시간표가 있다고 해서 좌석이 있다는 뜻은 아닙니다.
- 좌석을 확인할 근거가 없으면 `확인 필요`로 표시합니다.
- 오래된 관측은 현재 상태처럼 표현하지 않습니다.
- 한 운영사의 조회가 실패해도 다른 운영사의 정상 결과는 유지합니다.
- 데모 데이터는 실제 시간표나 좌석이 아닙니다.

열차 이용이나 결제 전에는 공식 앱이나 홈페이지에서 최종 상태를 다시 확인하세요.

## 상태의 근거

좌석 상태에는 확인한 곳과 시각을 함께 표시합니다.

- 운영사 화면에서 확인한 값
- 사용자가 공식 화면에서 직접 확인해 입력한 값
- 화면 검증용 데모 값
- 확인하지 못한 상태

출처나 확인 시각이 없거나 형식이 올바르지 않으면 `확인 필요`로 표시합니다. 데모 값은 항상 데모라고 표시합니다.

## 자동화와 보호 조치

다음 신호가 나타나면 자동 요청을 계속하지 않습니다.

- 보안문자
- 접속 대기 화면
- 비정상 접근 안내
- 호출 제한
- 자동화 차단 또는 보호 응답

이런 보호 조치를 우회하거나, 프록시·IP·계정을 돌려가며 반복 요청하지 않습니다. 일정 시간 요청을 멈춘 뒤 공식 앱이나 홈페이지에서 직접 확인하도록 안내합니다.

## 대기와 알림

레일웨잇의 기본 역할은 관심 열차의 상태를 정리하고 변화가 있을 때 알려주는 것입니다.

- 같은 변화를 여러 번 알리지 않도록 중복을 줄입니다.
- 확인하지 못한 상태를 좌석 발견으로 알리지 않습니다.
- 좌석 감시를 활성화한 대기는 화면을 닫아도 서버가 실행 중인 동안 계속 확인할 수 있습니다.
- 알림 전송 실패가 좌석 상태를 성공으로 바꾸지는 않습니다.

알림은 확인할 시점을 알려줄 뿐 좌석 확보나 예약 성공을 보장하지 않습니다.

## 실험 기능

철도사 좌석 감시와 제한적인 예매 시도는 기본 설치에서 꺼져 있습니다. 좌석 감시는 운영사별 설정을 모두 켜야 하며, 예매 시도에는 로그인 확인을 마친 철도 계정과 별도 활성화가 추가로 필요합니다.

예매 시도 기능의 원칙:

- 같은 좌석 가용 상태가 이어지는 동안 최대 한 번만 요청합니다.
- 결과가 불확실하면 같은 요청을 자동으로 반복하지 않습니다.
- 인증이 필요하거나 보호 응답이 나타나면 중단합니다.
- 공식 예약 내역에서 결과를 다시 확인하도록 안내합니다.
- 결제 단계 전에 멈춥니다.

실험 기능은 운영사 환경에서 안정적인 동작을 보장하지 않습니다. 운영사는 화면과 정책을 언제든 바꿀 수 있습니다.

## 예약과 결제

레일웨잇은 다음 기능을 제공하지 않습니다.

- 자동 결제
- 카드 번호, CVC, 간편결제 인증정보 저장
- 결제기한 임의 생성
- 공식 확인 없이 예약 성공 처리

결제 필요 상태가 표시되면 공식 앱이나 홈페이지에서 예약 내역, 좌석, 결제기한을 확인한 뒤 사용자가 직접 결제합니다.

## 철도 계정

철도 계정은 운영사별로 한 개씩 저장할 수 있습니다.

- 로그인에 성공한 값만 저장합니다.
- 비밀번호와 알림 비밀값은 암호화합니다.
- 브라우저에는 일부를 가린 아이디와 확인 상태만 보여 줍니다.
- 비밀번호, 쿠키, 토큰을 URL·로그·알림에 넣지 않습니다.
- 인증이 만료되면 관련 예매 시도를 중단합니다.

운영자는 `.env`, 데이터베이스, 백업과 서버 계정을 함께 보호해야 합니다.

## 공식 채널로 이동하기

레일웨잇은 고정된 공식 HTTPS 주소만 사용합니다. 여정 정보를 복사해 공식 화면에서 다시 입력할 수 있도록 돕습니다.

- 링크를 열었다고 해서 좌석이 확인되거나 예약이 성공한 것은 아닙니다.
- URL에 비밀번호, 쿠키, 토큰, 결제정보를 넣지 않습니다.
- 다른 도메인이나 확인되지 않은 경로는 공식 링크로 사용하지 않습니다.

## 개인정보와 로그

로그와 화면에는 운영에 필요한 최소 정보만 남깁니다.

기록하거나 공유하지 않는 정보:

- 원문 비밀번호
- 세션 쿠키와 브라우저 저장 상태
- API token과 암호화 키
- 카드정보와 결제 인증정보
- 전체 `.env`와 평문 Compose 설정

오류 메시지는 내부 응답 원문 대신 사용자가 취할 수 있는 행동을 설명합니다.

## 기여 범위

다음 변경은 프로젝트 범위에 포함하지 않습니다.

- CAPTCHA, 접속 대기, 호출 제한 우회
- 비공개 API 주소 복제
- 프록시·IP·계정 회전
- 공격적인 폴링
- 자동 결제와 결제정보 저장
- 근거 없는 좌석 상태 추정

기여자는 공식 서비스와 타사 자료의 저작권, 상표, 개인정보와 재배포 조건을 확인해야 합니다.

## 운영자가 직접 확인할 항목

다음 항목은 설치 환경에 따라 직접 확인해야 합니다.

- 공개 도메인과 HTTPS
- 실제 Web Push와 외부 알림 수신
- 실기기 PWA
- 암호화 백업 복원
- 철도사 계정의 장시간 유지
- 실험 기능의 장시간 안정성
