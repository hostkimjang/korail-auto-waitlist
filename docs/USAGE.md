# 사용 안내

레일웨잇의 기본 사용 흐름을 설명합니다. 화면에 표시되는 좌석과 예약 정보는 공식 앱이나 홈페이지에서 최종 확인해야 합니다.

## 새 대기 만들기

1. 메뉴에서 `새 대기`를 선택합니다.
2. KTX 또는 SRT를 고릅니다. 두 운영사를 함께 선택할 수도 있습니다.
3. 출발역, 도착역, 출발일과 시간 범위를 정합니다.
4. 관심 열차의 일반실 또는 특실을 선택합니다.

열차와 좌석 등급마다 대기가 하나씩 만들어집니다. 같은 열차의 일반실과 특실을 각각 등록할 수 있습니다.

## 홈 화면

홈에서는 지금 확인해야 할 항목과 감시 중인 대기를 볼 수 있습니다.

- `감시 중`: 좌석 상태 변화를 확인하고 있습니다.
- `좌석 확인 필요`: 최근 상태를 확정할 정보가 없습니다.
- `좌석 발견`: 공식 앱이나 홈페이지에서 다시 확인할 시점입니다.
- `결제 필요`: 예매 시도 결과 결제가 필요한 것으로 확인된 상태입니다. 실제 예약 내역과 결제기한은 공식 앱이나 홈페이지에서 확인하세요.
- `인증 필요`: 저장한 철도 계정의 로그인을 다시 확인해야 합니다.

정보가 오래됐거나 근거가 충분하지 않으면 `좌석 확인 필요`로 표시합니다.

## 대기 관리

감시 중인 항목에서 다음 작업을 할 수 있습니다.

- 잠시 멈추기
- 다시 시작하기
- 대기 취소하기
- 좌석을 발견했을 때 할 일 변경하기

`알림만 받기`는 상태가 바뀌었을 때 알려주고 감시를 계속합니다. 실험 기능과 철도 계정 설정을 모두 마친 경우에만 제한적인 예매 시도 옵션을 사용할 수 있습니다.

## 알림

설정 화면에서 알림 채널을 연결할 수 있습니다.

- 브라우저 푸시 알림
- Telegram
- Discord
- Webhook

연결한 채널은 이후 발생하는 알림에 적용됩니다. 실제 외부 채널 수신은 운영 환경에서 직접 시험해야 합니다.

## 공식 플랫폼으로 이동하기

좌석 확인이나 결제가 필요하면 공식 앱·홈페이지에서 다시 확인할 수 있도록 여정 정보를 정리해 줍니다.

- 공식 페이지가 자동으로 좌석을 확보했다고 보지 않습니다.
- 공식 페이지를 열었다는 이유만으로 예약 성공으로 처리하지 않습니다.
- 결제기한이 제공되지 않으면 임의의 남은 시간을 만들지 않습니다.
- 결제는 사용자가 직접 진행합니다.

## 설정

설정 화면에서는 다음 항목을 관리합니다.

- 철도 계정
- 알림 채널
- 화면 갱신 주기
- 좌석 확인 주기
- 로그와 진행 상태

화면 갱신 주기를 짧게 설정해도 철도사 조회가 같은 간격으로 늘어나지는 않습니다. 철도사의 호출 제한과 보호 안내가 설정값보다 우선합니다.

## 문제가 생겼을 때

먼저 설정의 `로그·진행 상태`에서 현재 상태를 확인하세요. 원문 비밀번호나 토큰은 화면에 표시되지 않습니다.

서비스가 시작되지 않거나 알림이 오지 않으면 [설치·운영 가이드](OPERATIONS.md#문제-해결)를 참고하세요.
